# HIGHLIGHTS.md format

One file, newest entry at the bottom. Two kinds of entry: a **highlight** (a line the reader reacted to) and **feedback** (a correction to how you explained something). Keep each entry short enough to scan.

```markdown
# Highlights

## 2026-10-23 highlight: one-shot memory as a high learning rate
> In gradient terms, the learning rate is high enough that one example moves the weights substantially. That is what lets a rat store "food was in the left arm" on one exposure.

Reaction: "wow, that's powerful." Context: brain memory versus model, the CA3 write. Status of the claim: inference (the theory needs it; no matched measurement). Source: thread "Memory versus model in the brain".

## 2026-10-23 feedback: textbook certainty on neuroscience
Did: stated the CA3 one-shot story as fact, with a wrong number (2% active cells is dentate gyrus, CA3 is 15 to 30%).
Wanted: solid / model / inference on each claim, and what the field does not know.
```

Rules:

- Quote the line verbatim. Do not tidy it.
- Record the reaction in the reader's words.
- Carry the claim's certainty tag into the entry, so a highlight that was an inference stays marked as one.
- Never remove an entry. If a highlight later turns out wrong, add a new entry that says so and links back.
